Run your first time-control demo / 第一個時間控制示範

Extract the Spacetime source ZIP and open its folder. Python ≥ 3.12. The demo and gates need no model or API key.

解壓 Spacetime 原始碼，在該資料夾開啟終端機。完整套件中的位置是 packages/spacetime。示範作用於本次建立的模擬 runtime。

python -m venv .venv
# Windows PowerShell
.venv/Scripts/python.exe -m pip install -e ".[dev]"
.venv/Scripts/pss.exe temporal-demo --rate 2.5 --quanta 20
.venv/Scripts/pss.exe matrix C_EVENT_SPARSE
.venv/Scripts/pss.exe gate --git-commit UNKNOWN

Linux/macOS: use .venv/bin/python and .venv/bin/pss.

Expected demo result: receipt_status: CONFIRMED, realized rate 2.5, logical tick 50, counter 2, phase complete, and equal tick/event-jump state hashes. Event jumping skips 47 idle ticks while preserving the same state.

邏輯時間倍率和 CPU 配額是不同能力。原生時間控制目前由 synthetic runtime 提供；一般作業系統行程的 CPU 限速不會自動改寫其邏輯時鐘。Provider 能力、目標擁有權與 authority grant 分別檢查。

Verify and compare / 驗證與比較

.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/pss.exe compare runs/<run-a> runs/<run-b>

The matrix runs B0–B3 under one correctness contract. Gate 0–6 check schema integrity, observation, actuation authority, temporal semantics, causal governance, AI fallback, and benchmark integrity. Reports preserve failures and unsupported controls.

Most bundled workloads are synthetic. Hard-gate success does not establish that B2 outperforms B1 or B3 outperforms B2. The current B3 fixture exercises the policy adapter without a paid model call.

目前是可執行的參考 runtime。效能優勢仍需重複實驗；一般 OS 程式的全面時間虛擬化與託管控制服務尚未提供。
