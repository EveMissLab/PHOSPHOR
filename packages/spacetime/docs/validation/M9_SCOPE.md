# M9 Benchmark Harness Validation Scope

M9 establishes the reproducible benchmark machinery and B0/B1/B2/B3 baseline contract. CI hard-gates artifact completeness, manifest validation, correctness preservation, invalid-run retention, comparison compatibility warnings, M8-bounded B3 policy behavior, and the existing native Linux/Windows provider regressions. M9 does **not** treat B2>B1 or B3>B2 performance as a pass condition; performance values remain evidence/hypotheses until formal repeated benchmark runs.
